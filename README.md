The script `compress_arrow.py` will take e.g. the following files from `data_folder`:
  - `NeuropixelsV2_ProbeB_AmplifierData_0.bin` -- an ephys file
  - `NeuropixelsV2_ProbeB_HubClock_0.bin` -- a hubclock file
  - `NeuropixelsV2_ProbeB_Clock_0.bin` -- a clock file

And combine them into a `NeuropixelsV2_ProbeB_AmplifierData_0.arrow` arrow file, with standard `zstd` level 3 compression. This matches the output generated by the Bonsai Onix system when exporting arrow files.

Compress with e.g. 
```
uv run compress_arrow.py --data_folder=path/to/folder/with/files/inside --output_folder='output/folder/ --probe_name='ProbeB' --file_index=0
```

Validate a file `data_folder` against all files in an `output_folder` with e.g.
```
uv run validate.py --data_folder=path/to/folder/with/files/inside --output_folder='output/folder/ --probe_name='ProbeB' --file_index=0
```

If a clock file is shorter than an ephys file (often happens at end of epoch), the clock files are padded with pyarrow null values.

If the ephys file is shorter than a clock file (happens in the robocopy error files), the clock files are cut short to match the length of the ephys files. This is technically a deletion of raw data. But the data are timestamps that correspond to nothing.
